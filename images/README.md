# Wiring image archive

These are unmodified copies of the original RC-EX3 wiring and installation
images from [`hump-coder/mhi-rc-ex3-esp32`](https://github.com/hump-coder/mhi-rc-ex3-esp32).
They are stored locally so this repository's hardware guide remains usable if
the original repository or its raw-image URLs become unavailable.
